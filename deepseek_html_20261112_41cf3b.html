1 Introduction to Binary OperationsObj. 5.5 By the end of the lesson, students will be able to evaluate expressions involving binary operations other than the four basic operations (addition, subtraction, multiplication, division).

Binary Operation: an operation that combines two elements to produce a third element.

  • a ⊕ b = a2 + b2
  • a ⊗ b = 2a + 3b
  • Students substitute given values and evaluate using order of operations.
  1. Hook: Brainstorm — "What does the word 'operation' mean in maths?" Review the four basic operations; introduce new operations.
  2. Direct Instruction: Define binary operation. Worked example — If a ⊕ b = a2 + b2, find 3 ⊕ 4.
  3. Guided Practice: Pairs evaluate 5 ⊗ 2 where a ⊗ b = 3a − b.
  4. Independent Practice: Worksheet with 10 evaluation problems.
  5. Exit Ticket: Evaluate 7 ★ 3 given a ★ b = ab − a.
 Whiteboard, markers, worksheets, projector.
  • Struggling learners: Formula card with step-by-step substitution guide; reduced number of problems.
  • Advanced learners: Operations with three variables or nested operations.

Formative: Observation during guided practice; exit ticket.

Summative: Worksheet graded for completion and accuracy.
2 Commutative, Associative & Distributive PropertiesObj. 5.5 By the end of the lesson, students will be able to identify and apply the commutative, associative and distributive properties.
  • Commutative: a + b = b + a; a × b = b × a (order does not matter).
  • Associative: (a + b) + c = a + (b + c); (a × b) × c = a × (b × c) (grouping does not matter).
  • Distributive: a(b + c) = ab + ac.
  1. Warm-up: Quick mental maths problems.
  2. Discovery Activity: Students use number cards to test whether order/grouping changes results.
  3. Direct Instruction: Formal definitions with examples.
  4. Partner Work: Identify which property is used in given equations.
  5. Independent Practice: 15 problems applying properties to simplify expressions.
  6. Closure: Summarise key differences between the properties.
 Number cards, whiteboard, worksheets.
  • Visual learners: Colour-coded highlighting for each property.
  • Kinesthetic learners: Manipulatives (counters) to demonstrate grouping.
  • ELL students: Bilingual vocabulary cards.

Formative: Thumbs up/down checks; partner discussion observation.

Summative: Property identification quiz (5 questions).
3 Substitution in Algebraic ExpressionsObj. 5.6 By the end of the lesson, students will be able to substitute numbers for variables in algebraic expressions.

Substitution: Replacing variables with given numerical values and simplifying using order of operations (PEMDAS/BODMAS).

Key terms: variable, constant, coefficient, term, expression.
  1. Review: Quick recall of order of operations.
  2. Direct Instruction: Model substitution — evaluate 3x + 2y when x = 4, y = 5.
  3. Guided Practice: Evaluate 2a2 − 3b when a = 3, b = 2.
  4. Stations Activity: 4 stations of substitution problems at different difficulty levels.
  5. Independent Work: 12 substitution problems.
  6. Exit Ticket: Evaluate 5m − 2n + 7 when m = 6, n = 4.
 Whiteboard, station cards, worksheets, calculators (optional).
  • Struggling learners: Expression templates with blanks provided.
  • Advanced learners: Expressions involving fractions and exponents.

Formative: Station work observation; exit ticket.

Summative: Homework assignment (10 substitution problems).
4 Expanding Algebraic Expressions (Distributive Law)Obj. 5.7 By the end of the lesson, students will be able to apply the distributive law to expand algebraic expressions.
  • Expanding: a(b + c) = ab + ac
  • Extension: (a + b)(x + y) = ax + ay + bx + by
  • Key concept: Each term in the first bracket multiplies each term in the second bracket.
  1. Warm-up: Review distributive property with numbers.
  2. Direct Instruction: Expand 3(x + 4), then 2x(3x − 5).
  3. Guided Practice: Expand (x + 2)(x + 3) using FOIL.
  4. Pair Activity: "Expand & Trade" — students expand, then exchange with a partner to check.
  5. Independent Practice: 15 expansion problems (monomial × binomial, binomial × binomial).
  6. Closure: Quick quiz — expand 4(2x − 3) and (x + 5)(x − 2).
 Whiteboard, worksheets, algebra tiles (optional).
  • Visual learners: Area models (rectangles) to show expansion.
  • Struggling learners: Step-by-step checklists.
  • Advanced learners: Trinomial × binomial expansion.

Formative: Pair activity observation; closure quiz.

Summative: Worksheet graded.
5 Factorising Algebraic ExpressionsObj. 5.13 By the end of the lesson, students will be able to factorise simple algebraic expressions using common factors.

Factorising (Common Factor): Find the highest common factor (HCF) of the terms and write as a product.

  • ax + bx = x(a + b)
  • ax2 + bx = x(ax + b)
  • Key concept: Factorising is the reverse of expanding.
  1. Warm-up: Find the HCF of numbers (e.g., HCF of 12 and 18).
  2. Direct Instruction: Factorise 6x + 9 = 3(2x + 3).
  3. Guided Practice: Factorise 8x − 12 and 15x2 + 10x.
  4. "I Do, We Do, You Do" strategy.
  5. Independent Practice: 12 factorising problems.
  6. Exit Ticket: Factorise 14x − 21 and 9x2 + 6x.
 Whiteboard, worksheets, factor cards.
  • Struggling learners: Provided list of common factors.
  • Advanced learners: Factorise expressions with negative common factors.

Formative: Exit ticket; observation.

Summative: Quiz 1 (covers Lessons 1–5) — 20 minutes.
6 Quiz 1Quiz 1 (Lessons 1–5) & Introduction to Algebraic FractionsObj. 5.8 By the end of the lesson, students will demonstrate understanding of binary operations, properties, substitution, expansion and factorisation; and begin simplifying algebraic fractions.

Quiz content: binary operations; commutative, associative and distributive properties; substitution; expansion; factorisation.

Algebraic Fractions: fractions with variables in the numerator and/or denominator; simplified by cancelling common factors.
  1. Quiz (20 min): 15 questions covering Lessons 1–5.
  2. Introduction to Algebraic Fractions: Define; show 6x9 = 2x3.
  3. Guided Practice: Simplify 12ab18a and 5x210x.
  4. Independent Practice: 8 simplification problems.
  5. Closure: Recap key points.
 Quiz papers, whiteboard, worksheets.
  • During quiz: Read aloud for students with reading difficulties; extended time if needed.
  • For fractions: Visual fraction models.

Summative: Quiz 1 graded.

Formative: Fraction simplification observation.
7 Operations on Algebraic FractionsObj. 5.8 By the end of the lesson, students will be able to perform the four basic operations (+, −, ×, ÷) on algebraic fractions.
  • Addition / Subtraction: Find a common denominator, then add/subtract the numerators.
  • Multiplication: Multiply numerators and multiply denominators.
  • Division: Multiply by the reciprocal.
  • Key principle: The same rules apply as for numerical fractions.
  1. Review: Numerical fraction operations.
  2. Direct Instruction: Demonstrate each operation with algebraic fractions:
    • Addition: 2x + 3x = 5x
    • Multiplication: 2x × x3 = 23
    • Division: 2x ÷ 3y = 2y3x
  3. Guided Practice: Work through examples step by step.
  4. Group Activity: "Fraction Operation Relay" — groups compete to solve problems.
  5. Independent Practice: 12 operation problems.
 Whiteboard, worksheets, fraction operation cards.
  • Struggling learners: Operation flowcharts provided.
  • Advanced learners: Fractions with quadratic denominators.

Formative: Relay observation; group work.

Summative: Worksheet graded.
8 Laws of Indices (Integral Indices)Obj. 5.9 By the end of the lesson, students will be able to use the laws of indices to manipulate expressions with integral indices.
  • (i) xm × xn = xm+n
  • (ii) xm ÷ xn = xm−n
  • (iii) (xm)n = xmn
  • (iv) x−m = 1xm
  • Key concept: Integral indices — positive and negative integers (m, n ∈ ℤ).
  1. Warm-up: Expand x3 × x2 as x·x·x·x·x.
  2. Direct Instruction: Introduce each law with worked examples.
  3. Guided Practice: Apply the laws to simplify expressions.
  4. "Law Sort" Activity: Match expressions to the correct law.
  5. Independent Practice: 15 simplification problems.
  6. Exit Ticket: Simplify x5 × x−2 and (x3)4.
 Whiteboard, law cards, worksheets.
  • Visual learners: Colour-coded law cards.
  • Struggling learners: Law reference sheet provided.

Formative: Exit ticket; law sort observation.

Summative: Practice worksheet.
9 Solving Linear EquationsObj. 5.10 By the end of the lesson, students will be able to solve linear equations in one unknown.

Linear equation: ax + b = c, where a ≠ 0.

  • Steps: Isolate the variable using inverse operations (addition/subtraction; multiplication/division).
  • Key concept: Balance — whatever you do to one side, do to the other.
  1. Warm-up: Solve simple equations mentally (e.g., x + 5 = 12).
  2. Direct Instruction: Model solving 3x + 7 = 22.
  3. Guided Practice: Solve 5x − 3 = 17 and 2x + 9 = 25.
  4. "Equation Balance" Activity: Use balance scales (physical or digital) to demonstrate.
  5. Independent Practice: 10 equations with the variable on one side; 5 with variables on both sides.
  6. Closure: Check solutions by substitution.
 Balance scale (physical/digital), whiteboard, worksheets.
  • Struggling learners: Equation-solving flowcharts.
  • Advanced learners: Equations with fractions and brackets.

Formative: Balance activity observation; closure check.

Summative: Homework assignment (10 equations).
10 Solving Linear InequalitiesObj. 5.11 By the end of the lesson, students will be able to solve simple linear inequalities in one unknown and represent solutions using set builder notation.
  • Linear inequality: ax + b < c; >; ≤; ≥.
  • Key rule: When multiplying or dividing by a negative number, reverse the inequality sign.
  • Set builder notation: {x : x > 3} means "all x such that x > 3".
  1. Warm-up: Compare equations vs inequalities.
  2. Direct Instruction: Solve 2x − 5 < 9, then 3x + 4 ≥ 19.
  3. Guided Practice: Solve and represent on a number line and in set builder notation.
  4. "Inequality Bingo" — students solve and mark answers.
  5. Independent Practice: 8 inequalities.
  6. Exit Ticket: Solve −2x + 3 ≤ 7 and write the answer in set builder notation.
 Number lines, whiteboard, bingo cards, worksheets.
  • Visual learners: Extensive use of number lines.
  • Struggling learners: Inequality rules card.

Formative: Bingo activity; exit ticket.

Summative: Practice worksheet.
11 Changing the Subject of FormulaeObj. 5.12 By the end of the lesson, students will be able to change the subject of formulae, including y = mx + c, C = 2πr and y = c / (2x).

Subject of a formula: the variable expressed in terms of the other variables.

  • y = mx + c → make x the subject: x = (y − c) / m
  • C = 2πr → make r the subject: r = C / (2π)
  • y = c / (2x) → make x the subject: x = c / (2y)
  1. Warm-up: Review inverse operations.
  2. Direct Instruction: Demonstrate each type step by step.
  3. Guided Practice: Change the subject for given formulae.
  4. "Formula Scavenger Hunt" — find and rearrange formulae.
  5. Independent Practice: 10 rearrangement problems.
  6. Closure: Summarise the steps for rearranging.
 Whiteboard, formula cards, worksheets.
  • Struggling learners: Step-by-step templates.
  • Advanced learners: Formulae involving squares and square roots.

Formative: Scavenger hunt observation; closure.

Summative: Class Assignment (Lessons 6–11) — 30 minutes.
12 AssignmentClass Assignment & Worded ProblemsObj. 5.14 By the end of the lesson, students will demonstrate understanding of algebraic fractions, indices, equations, inequalities and subject of formulae; and solve worded problems involving linear equations and inequalities.

Assignment content: algebraic fractions, laws of indices, linear equations, linear inequalities, changing the subject.

Worded problems: Translate real-life situations into equations/inequalities and solve.

Key skill: Identify variables → form equation/inequality → solve → interpret the answer.
  1. Class Assignment (25 min): 20 questions covering Lessons 6–11.
  2. Introduction to Worded Problems: "John has 3 more than twice Mary's age. If John is 25, how old is Mary?"
  3. Guided Practice: "A number increased by 7 is at least 15."
  4. Independent Practice: 5 worded problems.
  5. Closure: Share solutions and strategies.
 Assignment papers, whiteboard, worksheets.
  • During assignment: Read questions aloud; extended time.
  • For word problems: Sentence frames for translating.

Summative: Class Assignment graded.

Formative: Word-problem observation.
13 Identities & Review for Final TestObj. 5.15 By the end of the lesson, students will be able to prove two algebraic expressions to be identical and distinguish between equations and identities.
  • Equation: true for specific values only — e.g., 2x + 3 = 7 is true only when x = 2.
  • Identity: true for all values — e.g., 2(x + 3) = 2x + 6 is true for all x.
  • Proof: Expand/factorise both sides to show they are equivalent.
  1. Warm-up: Decide whether 3(x + 2) = 3x + 6 is an equation or an identity.
  2. Direct Instruction: Define and distinguish; show proof by expansion.
  3. Guided Practice: Prove (x + 1)2 = x2 + 2x + 1.
  4. "Equation or Identity?" Sort Activity.
  5. Review Game: "Jeopardy" covering all topics.
  6. Final Test Preparation: Go over key concepts and practice questions.
 Whiteboard, sort cards, review materials.
  • Struggling learners: Identity proof templates.
  • Advanced learners: Prove more complex identities.

Formative: Sort activity; review game.

Summative: Final Test (next session) — covers all topics.

Final Test Specifications

Section A — Multiple Choice (10 questions)

  • Evaluating binary operations
  • Identifying properties
  • Results of substitution
  • Expanded / factorised forms
  • Applications of index laws
  • Solutions of equations
  • Solutions of inequalities

Section B — True or False (5 questions)

  • Statements about the properties
  • Equation vs. identity identification
  • Statements about index laws

Section C — Matching (2 sets of 5)

  • Match expressions to their expanded / factorised forms
  • Match equations to their solutions

Section D — Structured Questions (5 questions)

  • Evaluate a binary operation — (2 marks)
  • Expand and factorise expressions — (4 marks)
  • Simplify algebraic fractions — (3 marks)
  • Solve an equation and an inequality — (4 marks)
  • Change the subject and solve a worded problem — (4 marks)
